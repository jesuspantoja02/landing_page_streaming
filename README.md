# 🎬 PantojaFlix - Landing Page

Bienvenido a **PantojaFlix**, una landing page responsiva e interactiva diseñada para una plataforma de streaming de cine en casa y entretenimiento digital.

El proyecto cuenta con un diseño moderno con modo oscuro, tarjetas de contenido dinámicas, secciones de planes de suscripción, adaptación completa para dispositivos móviles y menú interactivo.

---

## 🚀 Características

* **Hero Principal**: Sección destacada con la película/serie del momento (*Stranger Things Temporada 5*).
* **Diseño Responsive**: Adaptado perfectamente a pantallas de escritorio, tablets y teléfonos móviles.
* **Navegación Interactiva**: Menú desplegable tipo hamburguesa para pantallas pequeñas con animaciones CSS/LESS.
* **Catálogo y Beneficios**: Secciones organizadas tipo grid para mostrar los beneficios del servicio y el contenido disponible.
* **Planes de Suscripción**: Tarjetas comparativas de precios (Básico, Premium 4K y Familiar).
* **Favicon Dinámico**: Icono integrado en la pestaña del navegador mediante Data URI en SVG.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5**: Estructura semántica de la página.
* **LESS / CSS3**: Preprocesador de estilos con variables, mixins y media queries para un diseño responsivo.
* **JavaScript (Vanilla)**: Lógica para la interacción del menú móvil y estado de la interfaz.
